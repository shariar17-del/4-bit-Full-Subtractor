# 4-bit-Full-Subtractor -Schematic and Layout 
4-bit Full Subtractor circuit designed and simulated in Cadence Virtuoso. Includes schematic, post-layout design, DRC/LVS verification, and timing analysis for CMOS implementation.
This repository contains the schematic, layout, and simulation results of a 4-bit Full Subtractor implemented using Cadence Virtuoso in CMOS technology.

## 🧩 Project Overview
- **Tool Used:** Cadence Virtuoso
- **Technology Node:** 90 nm CMOS
- **Design Type:** 4-bit Full Subtractor
- **Views Included:** Schematic, Layout, DRC/LVS, and Simulation Waveforms
